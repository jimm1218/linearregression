# 動態線性迴歸與離群值分析模擬器
##DEMO連結：https://linearregression-5btrp4e5xdoz5vqgslqqbo.streamlit.app/ ##

這是一個使用 Streamlit 建立的互動式網頁應用程式，旨在動態模擬線性數據、執行迴歸分析，並即時視覺化結果與離群值。
此腳本由 AI 程式碼助理 (Gemini Code Assist) 根據指定需求生成，相關 Prompt 請參考 [`PROMPT.md`](./PROMPT.md)。

## 專案功能

-   **互動式參數調整**: 透過側邊欄的滑桿，即時調整數據點數量 (n)、真實斜率 (a)、截距 (b) 以及雜訊變異數 (var)。
-   **即時視覺化**: 參數變動時，圖表會立即重繪，展示數據分佈、迴歸線與離群值的變化。
-   **線性迴歸分析**: 使用 `scikit-learn` 函式庫找出數據的最佳擬合線，並計算出斜率 (a) 與截距 (b)。
-   **離群值識別**: 計算每個點與迴歸線的殘差，並找出距離最遠的前 10 個點作為離群值。
-   **可重現的隨機性**: 包含一個按鈕來重新生成數據雜訊，同時在調整參數時保持數據點的相對穩定性，提供流暢的操作體驗。

## 環境設置

在執行此腳本之前，請確保您已安裝所有必要的 Python 函式庫。

1.  確認專案資料夾內包含 `requirements.txt` 檔案。
2.  執行以下指令安裝所有依賴項：

```bash
pip install -r requirements.txt
```

## 如何執行

1.  將 Python 程式碼儲存為檔案（例如 `lineregression.py`）。
2.  打開您的終端機或命令提示字元。
3.  執行以下指令：

```bash
python lineregression.py
```

腳本執行後，將會在終端機印出分析結果，並彈出一個包含視覺化圖表的視窗。
